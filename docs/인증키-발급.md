# 인증키 발급 안내

두 곳에서 각각 하나씩. 둘 다 **무료·자동승인**이고 합쳐서 15분쯤 걸립니다.
계정 로그인이 필요해 제가 대신 할 수 없는 부분입니다.

---

## 1. 서울 열린데이터광장 → `SEOUL_KEY`

서울 1,288건(시설대관 611 + 체육시설 677)을 전량 받는 데 씁니다.

**① 회원가입** — 서울시 **통합회원** 계정을 씁니다. 서울시 홈페이지 계정이 이미 있으면 그대로 로그인하면 됩니다.
<https://www.seoul.go.kr/member/join/regist01.do?SITE_GB=GB071>

**② 인증키 신청**
<https://data.seoul.go.kr/together/mypage/actkeyMain.do>

- 페이지에 **「일반 인증키 신청」**과 「실시간 지하철 인증키 신청」 두 개가 있습니다
- **「일반 인증키 신청」**을 누르세요. 지하철 쪽은 위치기반 사업 신고필증이 필요한 별개 건이고 우리와 무관합니다
- 활용 용도를 적는 칸이 나오면 그대로 쓰시면 됩니다:
  > 공공시설 무료·실비 대관 정보를 지역·인원 조건으로 검색하는 비영리 웹사이트 제작

**③ 발급된 키 확인**
<https://data.seoul.go.kr/together/mypage/actkeyMng_ss.do>

신청 즉시 발급됩니다. 영문+숫자로 된 긴 문자열입니다.

> 참고 — 오픈API는 1회 호출당 최대 1,000건입니다. 수집기가 이미 1,000건씩 끊어서 부릅니다.
> 제약 없이 계속 쓰려면 나중에 활용사례(갤러리)에 사이트를 등록하면 됩니다. 지금은 필요 없습니다.

---

## 2. 공공데이터포털 → `DATA_KEY`

전국 표준데이터를 받아 **수도권 무료·실비가 실제 몇 건인지** 확정하는 데 씁니다. 판단 게이트가 여기서 갈립니다.

**① 회원가입 / 로그인**
<https://www.data.go.kr/uim/login/signupView.do>

**② 데이터 활용신청**
<https://www.data.go.kr/data/15013117/standard.do>

- 페이지에서 **오픈API 탭**으로 내려가 **「활용신청」** 버튼을 누릅니다
- 활용목적은 「웹 사이트 개발」을 고르고, 아래처럼 적으면 됩니다:
  > 공공시설 무료·실비 대관 정보를 지역·인원 조건으로 검색하는 비영리 웹사이트 제작
- **개발단계·운영단계 모두 자동승인**이라 바로 승인됩니다

**③ 발급된 키 확인**
<https://www.data.go.kr/iim/api/selectAPIAcountView.do>
(상단 마이페이지 → 오픈API → 인증키 발급현황)

> **주의 — `Decoding` 키를 쓰세요.**
> 발급 화면에 `Encoding`과 `Decoding` 두 가지가 나옵니다. 수집기는 URL 인코딩을 직접 하므로
> **Decoding 키**를 넣어야 합니다. Encoding 키를 넣으면 인증 오류가 납니다.

> 트래픽은 개발계정 기준 하루 10,000회입니다. 전국 데이터를 1,000건씩 받아도 수십 회면 끝납니다.

---

## 3. 키를 받은 뒤

키는 **채팅창에 붙여넣지 말고** 터미널에서 환경변수로 넘기세요. 저장소에도 커밋하지 마세요.

```bash
cd ~/Desktop/클로드작업/moilgot
SEOUL_KEY='발급받은키' python3 tools/collect_seoul.py
```

```bash
cd ~/Desktop/클로드작업/moilgot
DATA_KEY='발급받은Decoding키' python3 tools/collect_standard.py
```

매번 치기 번거로우면 `.env.local`에 넣어두고 불러 쓰면 됩니다. (`.gitignore`에 이미 제외돼 있습니다.)

```bash
printf "SEOUL_KEY=키\nDATA_KEY=키\n" > .env.local && chmod 600 .env.local
set -a; . ./.env.local; set +a; python3 tools/collect_seoul.py
```

## 4. 나오는 결과

- `collect_seoul.py` → 서울 1,288건의 **무료 비율**과 **자치구 분포**, 접수 상태 분포
- `collect_standard.py` → 수도권 **무료 몇 건 / 실비 몇 건**, 시군구 분포, 좌표·정원·전화 채워진 비율,
  그리고 **판단 게이트(1,500건) 통과 여부 자동 판정**

이 두 숫자가 나오면 Phase 1 범위가 확정됩니다.
