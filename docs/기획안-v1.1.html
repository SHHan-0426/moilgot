실사 후 수정된 결론

"수도권 3개 시도"는 성립하지 않는다. 실질은 서울 단독이다. 경기는 API가 사실상 멈춰 있고, 인천은 이름과 달리 7개 기관짜리다.

서울 — 유일하게 튼튼하다

서비스총건수
시설대관611
체육시설677
교육423
문화행사1,185
진료29

공간을 빌리는 것과 직접 관련된 건 시설대관 + 체육시설 = 1,288건. 23개 필드를 확보했고 필요한 게 거의 다 있다 — PAYATNM으로 무료 판별, SVCURL로 예약 딥링크, X·Y로 거리 계산, AREANM으로 자치구, SVCSTATNM으로 접수 상태.

핵심 확인

날짜 단위 빈자리 필드는 없다. 접수 상태와 접수 기간까지만 준다. 세 소스 어디에도 없었다. A층은 v1에서 뺀다.

경기 — 사실상 사용 불가

  • 총 49건. 31개 시군 통합이라는 설명과 실제 개방량이 전혀 다르다
  • 데이터 기준일 2024-09-11, 갱신주기 "주기없음" — 약 2년간 멈춰 있다
  • 사용료 필드가 아예 없다 → 무료·유료 판별 불가
  • 예약방법이 전화, 방문 — 온라인 예약도 아니다

인천 — 중간. 스크래핑이 필요하다

  • 공공데이터포털 등록이 API 유형 "LINK" — 포털에 REST 명세가 없다
  • 목록 페이지는 서버 렌더링이라 수집은 가능하다
  • 다만 통합회원 대관 운영기관은 7곳뿐. 나머지 군·구와 시설공단은 각자 별도 시스템에 별도 로그인이다
  • 목록에 요금 정보가 없다

전국 표준데이터 — 로그인이 필요하다

파일 다운로드는 비로그인 404, odcloud API는 401. 25개 항목에 유료사용여부·사용료·수용인원·위경도가 있어 여전히 최선의 백본이지만 분기 갱신이라 C층 전용이다.

그래서 기획을 이렇게 바꾼다

  1. Phase 1 지역은 서울로 확정. 수도권 균등 전개는 데이터가 뒷받침하지 않는다
  2. A층은 v1에서 제외. 배지는 🟡 접수 중과 ⚪ 전화 확인 두 층으로 시작하고, A층은 자리만 비워둔다
  3. 무료 판별이 되는 소스는 둘뿐 — 서울 PAYATNM과 전국 표준데이터 유료사용여부
  4. 경기·인천은 C층으로 시작. 인천만 스크래퍼로 B층 일부를 얹는다

문제 — 장소 구하기가 모임의 병목이다

소모임 운영자가 모임 하나를 잡을 때 실제로 하는 일:

  1. 공유누리·지자체 사이트·블로그를 돌며 후보를 모은다
  2. 각각 들어가 무료인지, 자격이 되는지, 인원이 맞는지를 따로 확인한다
  3. 그날 비었는지는 결국 전화로 묻는다
  4. 사이트마다 회원가입을 다시 한다

삼중 확인 지옥이다. 정보가 없어서가 아니라 흩어져 있고, 조건으로 좁힐 수 없고, 신선도를 알 수 없어서 생기는 문제다.

공유누리가 이미 있는데 왜 또 만드나 — 공유누리는 자원 카탈로그다. 유·무료가 섞여 있고 "우리 모임 조건에 맞는 곳"으로 좁히는 도구가 아니다. 이 사이트는 모임 하나를 성사시키는 도구다.

기술 구조

이미 검증된 오늘 뭐하지·공모 한눈에 패턴을 그대로 재사용한다.

인천 통합예약안내 API             │              │
전국 표준데이터 (분기)            ┘              ▼

                                       │
                                       ▼
                 시도별 분할 JSON 커밋  →  Netlify 자동 배포

  • 검색은 클라이언트에서. 전국을 통째로 받지 않고 시·도 단위 JSON 분할 로드
  • API 키는 Netlify 환경변수 + Function 프록시. 클라이언트 노출 금지
  • 지도는 v1 후순위. 목록과 거리 표시로 시작

최대 리스크는 화려한 기능이 아니라 데이터 정규화다. 주소 표기가 제각각이고, 사용료가 자유 텍스트이고, 시설명이 중복된다. 여기서 시간이 다 간다.

단계

Phase 0데이터 실사완료 · 2026.08.27

실사 결과는 위 Phase 0 실사 결과에 있다. 남은 것은 인증키 두 개뿐이다.

  1. 서울 API 실호출 — 완료. 23개 필드·서비스별 총건수 확보
  2. 경기 TBGSSFACILITY 호출 — 완료. 49건·요금 필드 없음 확인
  3. 인천 목록 파싱 — 완료. LINK형 API·통합기관 7곳 확인
  4. 전국 표준데이터 — 보류. 비로그인 다운로드 차단, 인증키 필요
  5. 남은 것 — SEOUL_KEY와 DATA_KEY 발급 후 수집기 실행
판단 게이트 — 수도권 무료+실비 유효 건수가 1,500건 미만이면 서울만으로 시작한다. DATA_KEY가 나오면 자동 판정된다.
Phase 1검색 MVP2주

서울 확정. 시설대관·체육시설 1,288건으로 검색 → 결과 → 상세 → 예약·전화까지 한 흐름을 완성한다. 배지는 🟡 접수 중과 ⚪ 전화 확인 두 층.

Phase 2수도권 확대와 지역 랜딩2주

경기·인천은 표준데이터 기반 C층으로 붙인다. 인천만 스크래퍼로 B층 일부를 얹는다. 지역 랜딩 자동 생성, 검색엔진 노출, 신고 버튼 운영.

Phase 3정밀도이후
