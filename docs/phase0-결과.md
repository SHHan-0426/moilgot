# Phase 0 데이터 실사 결과

실사일 2026.8.27 · 실행 도구 `tools/collect_*.py` · 원본 `data/out/`

---

## 한 줄 결론

**"수도권 3개 시도"는 성립하지 않는다. 실질은 서울 단독이다.**
경기는 API가 사실상 죽어 있고, 인천은 통합이라는 이름과 달리 7개 기관짜리다.
기획의 지역 전략을 서울 집중으로 바꿔야 한다.

---

## 1. 서울 — 유일하게 튼튼하다

`http://openapi.seoul.go.kr:8088/{KEY}/json/{서비스}/{시작}/{끝}/`

| 서비스 | 총건수 |
|---|---|
| 시설대관 `ListPublicReservationInstitution` | **611** |
| 체육시설 `ListPublicReservationSport` | **677** |
| 교육 `ListPublicReservationEducation` | 423 |
| 문화행사 `ListPublicReservationCulture` | 1,185 |
| 진료 `ListPublicReservationMedical` | 29 |

공간을 빌리는 것과 직접 관련된 건 **시설대관 + 체육시설 = 1,288건**.

확인된 23개 필드 — 필요한 게 거의 다 있다.

```
SVCID  SVCNM  PLACENM  AREANM(자치구)
SVCSTATNM      접수중 / 접수종료 / 예약마감
PAYATNM        무료 / 유료(요금안내문의)      ← 무료 판별 가능
SVCURL         yeyak.seoul.go.kr 예약 딥링크   ← 예약 연결 가능
X, Y           위경도                          ← 거리 계산 가능
RCPTBGNDT/RCPTENDDT   접수 시작·종료 일시
SVCOPNBGNDT/SVCOPNENDDT  운영 기간
V_MIN, V_MAX   이용 가능 시간(예: 09:00~18:00)
TELNO  USETGTINFO  DTLCONT  IMGURL  REVSTDDAY
```

**핵심 확인 결과 — 날짜 단위 빈자리 필드는 없다.**
접수 상태와 접수 기간까지만 준다. 기획의 A층(예약 가능 확인됨)은 서울 API만으로는 만들 수 없다.
→ **서울은 B층(접수 중)으로 확정한다.**

`sample` 키는 5건 제한이라 전량 집계에는 실제 인증키가 필요하다.

## 2. 경기 — 사실상 사용 불가

`https://openapi.gg.go.kr/TBGSSFACILITY` (인증키 없이 호출됨, 호출 제한 없음)

- **총 49건.** 31개 시군 통합이라는 설명과 실제 개방량이 전혀 다르다
- **데이터 기준일 2024-09-11 · 갱신주기 "주기없음"** — 약 2년간 멈춰 있다
- **사용료 필드가 아예 없다** → 무료/유료 판별 불가
- `RSVTN_METH`(예약방법)가 `전화, 방문` — 온라인 예약도 아니다
- 예약기간 필드는 대부분 비어 있다 (표본 5건 중 1건만 채워짐)

→ 경기는 예약 API로 못 쓴다. **전국 표준데이터(분기 갱신)로만 C층 커버.**

한 가지 주의: `openapi.gg.go.kr`는 User-Agent가 없으면 WAF가 "보안 정책에 의해 차단"으로 막는다. 수집기에 UA를 반드시 넣어야 한다.

## 3. 인천 — 중간. 스크래핑이 필요하다

- 공공데이터포털 `인천광역시_통합예약안내`(15085804)는 **API 유형이 "LINK"** — 포털에 REST 명세가 없다. 활용신청을 해도 인천시 자체 시스템으로 연결될 뿐이다
- 실제 목록 페이지(`incheon.go.kr/res/RE020101`)는 **서버 렌더링이라 수집 가능**
- 다만 통합회원 대관 운영기관은 **7곳뿐** — 계양공원사업소, 여성의광장, 월미공원사업소, 인재개발원, 인천광역시, 인천대공원사업소, 인천문화예술회관
- 나머지 군·구(제물포·영종·미추홀·연수·남동·부평·계양·서해·검단)와 시설공단은 **각자 별도 시스템 + 별도 로그인**
- 목록에 접수 상태·신청기간·운영기간·전화는 있으나 **요금 정보는 없다**

## 4. 전국 표준데이터 — 로그인이 필요하다

- 파일 다운로드(`/tcs/dss/stdFileDown.do`)는 비로그인 POST에 404
- odcloud API(`api.odcloud.kr/api/15013117/...`)는 401 "인증키는 필수 항목입니다"
- 25개 항목에 **유료사용여부·사용료·수용가능인원수·위경도**가 있어 여전히 최선의 백본
- 단 **분기 갱신** — C층 전용

## 기획에 반영할 변경 4가지

1. **Phase 1 지역은 서울로 확정한다.** "수도권 3개 시도 균등"은 데이터가 뒷받침하지 않는다.
2. **A층(날짜 단위 빈자리)은 v1에서 뺀다.** 세 소스 어디에도 없다. 배지는 🟡 접수 중 / ⚪ 전화 확인 두 층으로 시작하고, A층은 자리만 비워둔다.
3. **무료 판별이 되는 소스는 둘뿐이다** — 서울 `PAYATNM`, 전국 표준데이터 `유료사용여부`. 경기·인천 예약 목록으로는 무료 여부를 알 수 없다.
4. **경기·인천은 C층으로 시작한다.** 표준데이터 기반 목록 + 전화 버튼. 인천만 스크래퍼로 B층 일부를 얹는다.

```
DATA_KEY=발급키  python3 tools/collect_standard.py
```
